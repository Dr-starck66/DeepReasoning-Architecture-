## Verification in browser
At click, the verifier fetches a public GitHub Actions run plus a Lean source file from an immutable commit, checks the exact hash, bound theorem header, common proof escapes, run name and commit. It flags mathematically overbroad claims PARTIAL. User files never leave the browser except pre-existing public GitHub endpoints retrieved by the browser; this is not a high-security upload portal. A CI success does not certify mathematical semantics. The local HTML works as a static site but Web Crypto requires HTTPS or localhost.
