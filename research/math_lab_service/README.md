# ASTRA MATH LAB Ω — Service v0.4.1

**Public production:** https://astra-math-lab-omega.vercel.app/

## Purpose

A bounded, verifiable multi-domain mathematical discovery engine. Separate mathematical conclusions from general complexity claims and prize eligibility. No OpenAI API, paid LLM, token leakage, server daemon or GitHub Actions is required.

## Four independent research tracks

1. Number theory: automatically infer a small divisibility modulus by exact GCD search; accompany the discovered known identities with elementary general arguments (not just finite tests).
2. Graph theory: exhaustively enumerate graphs on at most five vertices, find and verify the C5 counterexample to χ(G)=ω(G).
3. Combinatorics: verify the Vandermonde identity and give a generating-function coefficient proof.
4. SAT/logic: construct a parity-based collision for signed 1/2-way marginal statistics and independently test SAT/UNSAT on 32 truth assignments. DOES NOT resolve P vs NP.

This is a bounded domain-plugin architecture, **not** a universal theorem prover and not a source of original prize-winning theorems.

## API

- `GET /api/health` — public availability (server responds on demand; no always-running process).
- `GET /api/research?date=YYYY-MM-DD` — re-compute the four exact bounded reports for a date, without database writes.
- `GET /api/history` — persisted **scheduled/manual** execution receipts, source explicitly labeled.
- `GET /api/run` — PROTECTED CRON ONLY. Requires `Authorization: Bearer $CRON_SECRET`, Vercel sends this with configured `CRON_SECRET`. Persists to Neon idempotently.

## v0.5.0 — autonomous conjecture cycle (23 November 2026)

The previous fixed four-reference-research endpoint remains available at `/api/research` and is explicitly presented as a baseline. New public read-only `/api/discover?date=YYYY-MM-DD&round=N` executes a finite, reproducible candidate generator using three configurable grammars: exact integer-polynomial fixed-divisor conjectures with universal discrete-Newton certificates, symbolic commutative-ring identities via polynomial normalization, and graph-measure conjectures disproved by enumerated counterexamples or marked `UNVERIFIED` when only finite cases survive. `round` is bounded to 0..100; it does not persist.

The existing production cron at 08:00 UTC (`/api/run`, authenticated) reads IDs of previously persisted candidates from the existing Neon `astra_math_lab_runs` table, generates a nonduplicating cycle with `discoverCycle(day, {seenIds})`, and persists the full report as JSONB using the current `(run_day,version)` key. No destructive migration, additional database, new schedule or new paid resource. The existing history endpoint now exposes the discovery IDs and counts, **not** the secrets.

**Proof boundary:** `PROVED_ELEMENTARY` applies only to identities with exact universal algebraic/finite-difference certificates. A graph finding with one exact counterexample can disprove a general conjecture. A conjecture that survives graphs with 4–5 vertices has `UNVERIFIED`, not `PROVED`. All academic originality and prize claims are `UNVERIFIED` or ineligible. These are grammar-based algorithms, not an unrestricted AI mathematician; no LLM is installed server-side and no general reward is guaranteed. Vercel Cron is scheduled but actual future platform invocation requires a separate receipt to mark `PASS`.

Run `npm test` before deploying and verify `/api/discover`, `/api/health`, `/api/research`, and `/api/history` against public HTTPS.
